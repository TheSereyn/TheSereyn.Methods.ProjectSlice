# M-002 — Connected Documents

## Outcome

A signed-in user can keep the same document library available across two devices after the local-first walking skeleton has been proven.

## Integrated Demonstration

1. Sign in on one device.
2. Create or update a document locally.
3. Open the same library on a second device.
4. Confirm the synced document is available there.

## Exit Criteria

- [ ] The synchronization slice acceptance criteria pass.
- [ ] The integrated demonstration passes.
- [ ] The local-first milestone remains coherent after synchronization is introduced.
- [ ] Current-system documentation reflects the connected workflow.
